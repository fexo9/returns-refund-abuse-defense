# Controlled Returns & Refund-Abuse Defense System


**A decision toolkit for online sellers — stop bleeding margin on returns.**
For Etsy / Shopify / Amazon / marketplace sellers, and agencies serving e-commerce clients.


You get **two workbooks** (no macros, works in Excel desktop + web and other spreadsheet apps):


- `Returns-Refund-Abuse-Defense-EN.xlsx` — full English workbook
- `Returns-Refund-Abuse-Defense-AR.xlsx` — full Arabic (RTL) mirror workbook


## What's inside (8 sheets)


| Sheet | What it does |
|---|---|
| README | How to use the workbook + honest scope notes |
| RETURN-COST | **True-return-cost calculator.** Enter your price, COGS, shipping, fees → get your true cost per return, cost as % of price, max sustainable return rate, projected monthly return cost, and a SUSTAINABLE / REVIEW POLICY / UNSUSTAINABLE verdict |
| POLICY-CHOICE | **Decision worksheet** comparing 4 policy options (free returns 30-day · buyer-pays shipping · flat return fee 14-day · exchange-first incentive). Score each 1–5 on cost control, conversion friendliness, abuse resistance → weighted winner + reasoning |
| ABUSE-SCAN | **Refund-abuse red-flag checklist.** Score 12 abuse patterns (wardrobing, bracketing, empty-box claims, switch fraud, chargeback-as-return, serial returning, review extortion, …) 0–3 → 0–100 risk score, LOW/GUARDED/HIGH/CRITICAL level, and recommended actions per level |
| RMA-SOP | **Pre-return authorization checklist** (RMA number, photo evidence, reason codes, refund-after-inspection…) + **inspection decision tree** with 4 disposition paths (resell as new / open-box discount / liquidate / dispose) and a recovery-value estimator |
| WORDING | **7 copy-paste policy clauses**: return window, who pays return shipping, restocking fee, final-sale categories, delivery-confirmation requirement, refund method & timing, abuse clause |
| TRAP-LIBRARY | **15 expensive traps** — the quiet ways sellers leak margin on returns, each with *why it costs money* and *the rule* that prevents it |
| DASHBOARD | **KPI summary** pulling live from the other sheets — print-friendly, review monthly |

## How to use


1. Open the workbook in your language. **Blue cells are your inputs** — white cells calculate automatically.
2. Sample data is pre-filled so every sheet works instantly. Replace it with your own numbers.
3. Start on **RETURN-COST**: if the verdict says REVIEW POLICY or UNSUSTAINABLE, go to **POLICY-CHOICE** and pick a better option.
4. Run **ABUSE-SCAN** honestly once a month; work the **RMA-SOP** checklist into your actual return process.
5. Copy the **WORDING** clauses to your store's policy page **after adapting them to your local consumer law**.


## Honest scope


- This is a **decision-support workbook** — calculators, checklists, and templates. It is **not legal advice**. Consumer return law varies by country and marketplace: adapt the WORDING clauses to your local law and platform rules before publishing.
- The workbook **cites no industry statistics** — every number you see is your own input or a calculation from it. Anyone else's "X% of sellers…" claims don't belong here.
- Formulas are error-guarded: bad inputs produce clean blanks, never spreadsheet errors. But garbage in still means garbage out — the ABUSE-SCAN only works if you score it honestly.
- Verified by automated recalculation (LibreOffice). Test report included: `TEST-REPORT.md`.
